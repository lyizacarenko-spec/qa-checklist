📋 SQL для создания таблицы
CREATE TABLE qa_records ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, manager text NOT NULL, date date NOT NULL, link text, score numeric(5,2), level text, state jsonb, comments jsonb, reviewer text, created_at timestamptz DEFAULT now() ); ALTER TABLE qa_records ENABLE ROW LEVEL SECURITY; CREATE POLICY "allow all" ON qa_records FOR ALL USING (true);
Запусти этот SQL в: Supabase → SQL Editor → New Query
